# CEN3031 Software Engineering Semester Project

This repository contains our group project for CEN3031: Introduction to Software Engineering at the University of Florida.

This project is a gamified music discovery application where users invest virtual tokens in emerging songs. As songs increase in popularity, users' virtual investments gain value. Users can build portfolios, add friends, and compete on social leaderboards.

## Planned Features

- User registration and authentication
- Multiple user types
- Music discovery and song information
- Virtual song investments
- User portfolios and token balances
- Friends and social leaderboards
- Central database for user and song data
